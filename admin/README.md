# Admin panel scaffold

This directory contains the admin panel frontend scaffold only.

- `login.html`: admin login page
- `dashboard.html`: admin dashboard and product management page
- `assets/css/style.css`: shared admin panel styles
- `assets/js/login.js`: login page interactions
- `assets/js/dashboard.js`: dashboard interactions

The `src/admin/` directory contains empty backend module folders. The existing cart backend has not been changed.

No authentication, database, API, or product-management logic has been implemented yet. Build those features as learning exercises.
